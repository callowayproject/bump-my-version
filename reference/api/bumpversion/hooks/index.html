format_hooks ​

python
def format_hooks(hooks: List[str], context: Dict[str, str]) -> List[str]

Replace known version placeholders in hook command strings.

Placeholders that do not match a key in context are left untouched. Values are shell-quoted (except on Windows) so whitespace or quotes in a value cannot add argv elements.
